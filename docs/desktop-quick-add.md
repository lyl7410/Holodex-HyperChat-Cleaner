# Holodex Quick Add — PC 桌面使用指南

当前通用版 **v0.3.0**。同一个油猴脚本同时支持 PC 和 Android，不需要另外安装 PC 脚本。

[安装 / 更新 Quick Add](https://raw.githubusercontent.com/lyl7410/Holodex-HyperChat-Cleaner/main/userscripts/holodex-mobile-quick-add.user.js) · [手机使用说明](mobile-quick-add.md) · [返回项目首页](../README.md)

## 安装与兼容性

- PC 建议使用 Chrome、Edge 或 Firefox，配合支持异步 `GM.setValue` 的 Tampermonkey / ScriptCat。尚未对所有浏览器与脚本管理器组合做完整实测。
- **不要额外安装一份 PC 脚本**，直接更新原来的 `holodex-mobile-quick-add.user.js`；为了确保覆盖现有安装，脚本头部的 `@name` 和 `@namespace` 保持旧值，功能已经升级为通用版。
- YouTube 和 Holodex 必须在同一个浏览器配置文件、同一个脚本管理器中运行这一个脚本。普通 / 无痕窗口、不同浏览器之间不共享队列。
- 升级后，请刷新已打开的 **YouTube 视频页**和 **Holodex Multiview 接收页**，确保双方都使用 v0.3.0。
- 如果安装了 PC 端 Holodex MultiView Assistant 扩展，建议先暂停该扩展的一键添加功能，避免两套入口同时添加。

## PC 便捷操作

| 场景 | 操作 | 预期行为 |
| --- | --- | --- |
| 快速发送当前视频 | 点击 YouTube 网页右下角半透明的 `＋H` | 发送至当前 Holodex 接收队列 |
| 鼠标悬停 | 将鼠标移到 `＋H` 上 | 按钮展开为「＋H 添加到多视图」 |
| 完全不用鼠标 | `Alt+Shift+H` | 快速发送当前视频 |
| 新建接收分屏 | **Shift＋点击** `＋H`，或 `Alt+Shift+N` | 新建接收目标，并尝试打开新的 Holodex 分屏 |
| 把已有分屏指定为接收端 | 在 Holodex Multiview 按 `Alt+Shift+R` | 认领当前分屏并检查队列 |
| 脚本菜单 | YouTube 或 Holodex 脚本管理器菜单 | 所有主要操作都有菜单后备入口 |

快捷键仅在 PC 的鼠标 / 精细指针模式启用；光标处于输入框、搜索框或可编辑文本时不会触发。若键位被系统或其他扩展占用，请使用 `＋H` 按钮或菜单。

浮动按钮默认收成小图标并保持低透明度，不会像手机那样每 4.5 秒完全隐藏。手机继续维持原有 4.5 秒自动隐藏和触摸时短暂显示的行为。PC 在 YouTube 视频页的通知显示为右侧窄面板，不会占据整个屏幕宽度。

## 接收页、后台工作与标签页

1. 第一次使用时，在 YouTube 视频页点击 `＋H`，脚本会尝试新开 Holodex Multiview 并设置接收目标。弹窗被浏览器阻止时，可能回退为当前页导航；允许网站打开标签页体验更好。
2. 后续添加到**已经指定**的接收页时，PC 端**不会主动切走 YouTube 标签页**；Holodex 接收页允许在后台处理队列。
3. 新视频添加成功后会反馈「已加入」。若 Holodex 标签页被浏览器休眠、网页尚未加载、脚本权限不足或接收页已经关闭，队列可能保持待处理状态，切回 Holodex 并按 `Alt+Shift+R` 可以再次处理。
4. 不会把「已保存到队列」误当成「视频已经添加成功」。跨标签页接收确认、视频去重和错误重试继续使用原 v0.2.3 的共享队列协议。
5. 后台**布局添加**与后台**视频自动播放**是两回事：即使成功添加，浏览器也可能阻止后台自动有声播放；切回 Holodex 后可能需要点击播放。

**重要：** 只有浏览器中同一脚本管理器的标签页之间可以传递消息，无法直接把视频发到另一台电脑、手机或不同浏览器。

## 布局选择

脚本优先采用 Holodex 中配置的默认自动布局。没有合适配置时：

- **PC**：优先 Holodex 内置桌面预设，必要时后退到移动预设。
- **Android**：优先 Holodex 内置移动预设，必要时后退到桌面预设。

视频真正添加时继续调用 Holodex 原生 Vuex / `setMultiview` 合并布局，没有自行计算固定平铺、不会改动 Cleaner 或频道头像脚本。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 没有 PC 按钮 | 必须打开具体的 YouTube 视频页；PC 按钮位于右下角、未悬停时较淡。刷新并检查脚本权限及是否误装两个版本。 |
| 快捷键没反应 | 检查键盘焦点是否在输入框；系统快捷键 / 其他扩展可能占用组合键。改用点击按钮。 |
| 视频排队但没加入 | 确认 Holodex 接收页没有被关闭或休眠；切回分屏使用「当前分屏接收」菜单或 `Alt+Shift+R`。 |
| 视频加入但没有播放 | 浏览器可能限制后台 / 有声自动播放，切回页面后尝试点击播放器播放。 |
| `E_STORAGE` | 检查异步 `GM.setValue` 权限，确认 ScriptCat / Tampermonkey 已更新；不要同时运行两个脚本管理器的副本。 |
| `E_LAYOUT` / `E_VUE` / `E_BRIDGE` | Holodex 原生布局接口或页面注入失败。确认页面加载完成、脚本授权正确，然后在接收页重试。 |
