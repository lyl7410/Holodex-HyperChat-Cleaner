# Holodex Mobile Quick Add

当前版本：**0.2.3**。用于在 YouTube 视频网页上点击一次，将当前视频加入同一个 Holodex 多视图。

[安装 / 更新脚本](https://raw.githubusercontent.com/lyl7410/Holodex-HyperChat-Cleaner/main/userscripts/holodex-mobile-quick-add.user.js) · [返回仓库说明](../README.md)

## 安装和更新

1. 在安卓浏览器中安装脚本管理器。当前基本使用流程的反馈环境为 **狐猴浏览器 + 脚本猫**；其他浏览器和管理器组合尚未完成实际验证。
2. 打开上面的安装链接，确认安装。若只显示代码，可在管理器中新建脚本，粘贴全部内容并保存。
3. 允许脚本在 YouTube 和 Holodex 上运行，并确认脚本存储、跨标签页值变化通知、页面访问及菜单等安装权限。更新时覆盖原来的同名脚本，不要安装成多份同时启用。
4. **刷新已打开的 YouTube 和 Holodex 标签页**，让两端加载同一版本。只更新管理器中的文件，不会替换已运行页面中的旧代码。

两端必须使用同一浏览器和同一脚本管理器中的同一份脚本。不要一端用普通模式、另一端用隐私模式，也不要分别安装到两个管理器中。

## 添加视频

1. 在浏览器内打开具体的 YouTube 视频网页。
2. 点击右下方的 **＋H**，或打开脚本猫菜单，选择「将当前视频加入 Holodex」。
3. 首次添加会打开一个 Holodex 接收页；若浏览器阻止新标签页，会尝试在当前标签页打开。
4. 后续从其他 YouTube 标签页点击添加，也会进入同一个接收队列。切回首次使用的 Holodex 页面，即可追加到该分屏。

支持 `watch?v=ID`、`shorts/ID`、`live/ID` 和 `youtu.be/ID`，包括 `m.youtube.com`。按钮读取的是点击时当前标签页 URL 中的视频 ID。Shorts 或 live 链接可识别，不代表相应视频一定允许嵌入播放。

“已排队”表示请求已保存，**不等于已加入布局**。手机可能冻结后台页面，需要切回 Holodex 后才处理。实际成功后显示已添加及对应视频 ID；同一视频已在目标布局中时不会再创建一份。

## 接收页和已有分屏

已有 Holodex 分屏可以直接成为接收页，不必重新创建：

1. 刷新该页面。
2. 若出现「使用此分屏接收」，点击即可；按钮隐藏后，也可打开脚本菜单，选择「使用当前分屏接收 / 检查队列」。
3. 接管后处理当前队列，后续添加继续进入这里。请保持这个页面打开。

新版接收页之间会检查接收归属，切换目标后原接收页停止消费队列。切换前请先刷新仍运行旧版脚本的页面。

如果原接收页已关闭，可打开另一个 Multiview 页面，使用上述菜单接管。发送页长时间未收到确认时，也会提供「新建接收页」入口；入口隐藏后触碰 YouTube 页面即可再显示。正常情况下无需反复新建。

## 默认布局

添加后调用 Holodex 原生 `setMultiview` 方法合并布局，使用以下顺序选择预设：

1. 优先使用 Holodex 中保存的**默认自动布局**，手机端也优先采用这组配置。
2. 在该组中先找视频数恰好匹配的预设；没有时，按配置顺序找第一个位置足够的预设。
3. 配置组无适用预设时，再尝试 Holodex 内置移动预设、内置桌面预设。

脚本不再自行计算等分网格。想使用自己的布局，需要在 Holodex 中将其保存并配置为相应视频数量的默认自动布局；仅手动切换当前布局，并不等同于修改默认设置。

原生合并方法负责迁移视频和重新关联聊天。新增后当前格子的位置及聊天区域安排会按目标预设变化；若要保留自定义排布，请先保存并配置为默认布局。

## 自动播放和音量

- 新增视频后，等待播放器就绪并尝试播放，首次尝试保留原音量设置。
- 有声播放受限时，新增视频会尝试静音播放；需要声音时可在播放器或 Holodex 媒体控制面板中手动开启。
- 切回分屏时，尝试恢复切走前观察到正在播放的视频；不是每次把所有原本暂停的视频都强制播放。
- 持续未能播放时会提示触碰页面重试，也可直接点击相应播放器的播放按钮。

自动播放仍受浏览器、YouTube 嵌入权限、视频限制和系统后台策略影响，不能保证每台手机都能自动有声播放。脚本不会通过重新载入视频来恢复播放。

## 观看时的入口

YouTube 上显示小型 **＋H**，闲置约 4.5 秒后隐藏，触碰页面后短暂显示。Holodex 成为接收页后不保留常驻接收按钮。普通提示约 6 秒后自动消失，错误提示会停留更久。

需要操作时可随时从脚本管理器菜单进入：

| 页面 | 菜单 |
| --- | --- |
| YouTube | 将当前视频加入 Holodex |
| Holodex Multiview | 使用当前分屏接收 / 检查队列 |

## 与其他脚本配合

Quick Add 是独立脚本，不要求 Cleaner 或 Channel Name Fix。它不改聊天输入框，不代理 Vuex getter，不包裹 mutation，也不自建频道资料抓取逻辑。

- **Cleaner**：负责聊天清理和发言入口。
- **Channel Name Fix**：负责频道名、标题和头像等资料修复。
- **Quick Add**：负责视频入口、共享队列、布局合并和播放尝试。

视频资料由 Holodex 原生方法加载；初始显示视频 ID 时可等待加载，或使用 Channel Name Fix。网站内部接口变化时仍可能需要分别调整脚本。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| YouTube 没有按钮 | 确认打开的是浏览器视频网页，脚本已启用且有网站权限；触碰页面让按钮显示，或使用脚本菜单。YouTube App 内不会出现按钮。 |
| 显示已排队，Holodex 没变化 | 切回 Holodex，并在菜单选择「使用当前分屏接收 / 检查队列」。若完全没有菜单或提示，检查 Holodex 网站权限及脚本启用状态，并刷新页面。 |
| 添加到的不是预期分屏 | 在想使用的那个分屏中执行接收菜单，重新指定目标。 |
| 第二个视频加入后布局不符 | 检查 Holodex 中相应视频数量的默认自动布局是否已保存，确认两端已刷新到 0.2.3 或更新版本。 |
| 视频暂停或没有声音 | 等待自动尝试；仍未播放则触碰页面或直接点击播放器。静音回退成功后，手动开启需要的声音。 |
| `E_STORAGE` | 重新安装当前版本并确认脚本存储授权，脚本猫需支持异步 `GM.setValue`。 |
| `E_VUE` / `E_BRIDGE` | 确认 Holodex 分屏自身加载正常、脚本允许页面访问/注入；保持前台后重试，并记录完整错误提示。 |
| `E_LAYOUT` | 检查默认预设是否有足够的视频位置；也可能是 Holodex 原生布局接口变化。修正设置后用接收菜单重试。 |

## 范围和验证情况

本脚本不包含收藏、观看历史、Twitch、直播探测、Android 原生分享接收或聊天清理功能。不能直接处理 YouTube App 的分享，需要先在浏览器打开视频网页。

队列在脚本管理器中保存请求、目标和处理状态，用于跨标签页通信；请求有效期为 12 小时，过期记录在接收扫描时清理。它不是收藏或观看历史功能。

当前用户反馈安卓狐猴浏览器 + 脚本猫的基本功能可用。本地模拟覆盖跨标签页队列、接收页接管、去重、默认布局原生合并、播放重试和切回恢复；这些不代替不同手机、浏览器和脚本管理器版本的完整真机回归。
