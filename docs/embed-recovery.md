# Holodex Embed Recovery v0.2.1

[安装脚本](https://raw.githubusercontent.com/lyl7410/Holodex-HyperChat-Cleaner/main/userscripts/holodex-embed-recovery.user.js)

源自 Nep 的 Holodex Multiview YouTube Embed Recovery，本版增加中文设置、检测与重试改进，以及 Edge 播放器复用。原英文 `@name` 和 `@namespace Nep` 保持不变；已有同名脚本应覆盖升级，保留配置，不要同时运行多个恢复版本。仓库不额外声明或变更上游授权。

## 安装与日常使用

1. 安装到 Tampermonkey 等脚本管理器，覆盖原同名 Recovery，只启用一份。
2. 刷新 Holodex，让父页面和 YouTube 嵌入播放器都加载新版。脚本需要在嵌入框内运行，脚本管理器需允许相关站点访问。
3. 油猴菜单“播放器恢复：中文设置”中可调整。每项均有默认值、范围和用途说明。保存设置会刷新整个 Holodex 页面，取消不保存。

本脚本仅处理可识别的 YouTube 视频格，不适配 Twitch；依赖 Holodex 当前的 VideoCell/Vue 接口与按钮结构，站点变更可能使其无法接管。

## Edge 复用模式

Edge 默认启用，其他浏览器默认关闭；可以在设置中切换，保存后刷新生效。关闭后将沿用旧恢复方式，包括可能触发中断的组件重建。

- 蓝色刷新与自动恢复共用单格互斥、冷却、退避和次数预算。使用当前播放器的 `loadVideoById`，不清空 Vue 引用、不替换 iframe、不清理站点原定时器。
- 保存并恢复当前格的音量和静音，音量0和静音false都有效。不主动操作其他格；播放状态及进度推进后才认为本轮恢复成功，成功不弹提示。
- 自动恢复时如关闭“恢复后自动尝试播放”，使用 `cueVideoById` 准备视频并提示手动播放；手动点击蓝色刷新仍视为明确播放意图，使用 load。待播不等于恢复成功。
- 用户在当前嵌入框点击、按键，或在当前格操作音量等控件，会保守取消未完成的恢复；打开播放器设置也可能取消等待。换视频、换播放器、移除或页面退出时取消旧任务。
- 接口缺失、异常或超时只显示提示并停止本轮，不自动退回销毁重建。连续点击不会绕过冷却和次数限制。
- **黄色返回和垃圾桶不拦截**，维持网站原生清空或删除行为。这会销毁播放器，仍可能引起其他格中断；本版不宣称真正删除已适配。

iframe保留不能证明内部媒体管线不重建；API进度推进也不能证明声卡和画面输出一定正常。Edge 模式属于绕过已观察到的触发路径，仍需真实浏览器确认效果。

## 默认设置

| 设置 | 默认 | 范围与说明 |
| --- | --- | --- |
| Edge播放器复用模式 | Edge开，其他关 | 仅缺少既有设置时按浏览器取默认值 |
| 恢复后自动尝试播放 | 开 | 浏览器仍可能阻止有声自动播放 |
| 画面卡住多久后恢复 | 3秒 | 1～120秒；调大可容忍短暂卡顿 |
| 持续转圈多久后恢复 | 12秒 | 3～180秒；慢网络可适当调大 |
| 两次恢复的最短间隔 | 15秒 | 0～600秒；0只关闭这项冷却 |
| 恢复结果最多检查次数 | 8次 | 1～16次；默认等待约20秒，后台可能更久 |
| 同格连续恢复上限 | 3次 | 1～8次，避免无限重试 |
| 退避基数 | 5秒 | 1～60秒，连续等待按倍数增长，与冷却取较长值 |
| 首次加载保护 | 10秒 | 0～60秒，与故障判定可同时计时，不是简单相加 |
| 正常播放后重置次数 | 30秒 | 5～120秒，必须持续有播放进度 |

配置继续使用 `RECOVERY_CONFIG_V2`（schema 2），保留旧配置键，新增 `edgeReuse` 布尔值。旧 `STALL_TICKS` 按原界面声明的秒数迁移；保留 false 和0。设置留空使用默认值，越界按边界保存，次数取整数。

同页各格预算独立；跨窗口冷却仅在相同origin及存储分区、支持Web Locks与存储时协调。无痕和普通窗口不能假定共享冷却。

## 与本仓库其他脚本共存

| 脚本 | 建议 |
| --- | --- |
| HyperChat Cleaner | 保留，验证聊天清理和界面正常 |
| Channel Name Fix | 保留，验证频道资料、头像和聊天切换正常 |
| Touch Controls | 先在其设置关闭“智能自动播放”，保留手势、统计、画质和倍速；不要让两套自动播放同时接管 |
| Quick Add | 基础验证先关闭，再原样启用，单独检查新增及布局合并 |
| 其他恢复/诊断脚本 | 旧恢复版关闭；诊断版仅排查时启用 |

上述是兼容配置建议，不代表所有版本组合已经过真实回归。验收时记录本机安装版本；仓库更新不等于浏览器里的脚本已同步升级。

## 已知边界

- 正常下播与意外结束未可靠区分：已播放直播退回结束界面，也可能触发有限恢复并开始回放。
- 用户主动暂停、普通视频结束不按常规卡死处理；复用的用户操作保护优先于后续自动控制。
- 返回、删除、预设布局切换、Quick Add原生布局调整及其他销毁入口，仍可能造成中断，不能从蓝色刷新成功推断它们也安全。
- 录像重新加载可能改变进度，本版不保证存档位置恢复。
- 非Edge默认保留旧恢复分支；不应把Edge复用“不重建”的边界套用到旧分支。

## 验证与回退

运行以下命令，不需要安装npm依赖：

```sh
node --check userscripts/holodex-embed-recovery.user.js
node tests/holodex-embed-recovery.test.cjs
```

70项模拟覆盖计时、缓冲、消息校验、配置迁移、原恢复回归、Edge复用、音频保存、失败无回退、用户取消、按钮放行及设置保存。模拟通过不代表线上Holodex适配完成。

实测先仅启用新版Recovery，用原复现的两个直播，蓝色刷新独立验证三轮、每轮观察其他格至少60秒；再逐步启用Cleaner、Name Fix、关闭智能自动播放的Touch Controls，最后验证Quick Add。卡住时记录具体操作、脚本版本、画面与声音变化。尚未在本仓库声明这些组合的真实验收通过。

回退可禁用本脚本并刷新；需要恢复旧版时从已有备份或仓库历史手动安装，避免新旧同开。关闭Edge复用模式不是已验证的修复方法，旧分支可能再现此前问题。
