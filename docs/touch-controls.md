# Holodex Touch Controls — Android 透明边缘手势与播放统计

当前版本：**v0.3.1（Android 兼容性修复）**。独立油猴脚本，在 Holodex Multiview 的 YouTube 小播放器边缘提供**无常驻图标**的音量与统计入口。

[安装 / 更新 v0.3.1](https://raw.githubusercontent.com/lyl7410/Holodex-HyperChat-Cleaner/main/userscripts/holodex-touch-controls.user.js) · [返回 README](../README.md)

## 为什么 v0.3.1 改用透明触控区？

v0.3.0 尝试直接在跨域 YouTube iframe 内监听触摸。安卓实测反馈：**右侧上下滑动导致整个页面滚动，左侧轻点没有反应**。这表明该方法在测试环境中没有正常接管触摸操作；第三方 iframe 脚本注入和 YouTube 播放器事件分发都可能造成兼容性问题，尚不能仅凭现象确定是哪一种。

因此 v0.3.1 **移除 iframe 内手势监听**，改为由 Holodex 页面自己的脚本在视频左右边缘创建非常窄的透明触控区。与 v0.2.x 不同，不再显示常驻 🔊 图标，也不再覆盖右侧 34% 的画面。透明触控区依旧会拦截它所占区域内的原生视频点击，这是触摸可靠性与无图标之间的取舍。

## 安装与更新

1. 使用脚本管理器更新 **Holodex Touch Controls** 同名脚本；关闭旧版本的重复副本。
2. 刷新整个 `https://holodex.net/multiview/`，确保父页面加载 v0.3.1。
3. 视频音量手势与左侧统计入口主要依赖 **Holodex 页面脚本**，不再以 YouTube iframe 脚本注入成功为前提。
4. 要读取 **YouTube Connection Speed** / Buffer Health / 原生分辨率，还需授权脚本在 `www.youtube.com/embed/*`、`www.youtube-nocookie.com/embed/*` 等第三方 iframe 中运行；不允许时相应字段将显示不可用。
5. 本脚本不要求安装 Quick Add、Cleaner、Channel Name Fix，也不修改它们。

## 操作

| 位置与手势 | 效果 |
| --- | --- |
| 视频右侧中部**透明窄条**（约 18% 宽，不超过 56px）向上滑 | 增大该路视频音量 |
| 同一区域向下滑 | 减小该路视频音量 |
| 视频左侧中部透明窄条**轻点** | 打开该路视频的精简播放统计 |
| 视频左侧透明窄条上下滑 | 仍允许正常滚动页面 |
| 视频中间、顶部或底部 | 继续使用 YouTube 原生交互 |
| 音量调整时 | 临时显示约 0.75 秒的音量百分比 |
| 统计面板 | 音量滑块、静音、±10、播放时间、分辨率等 |

左右触控条的纵向范围为画面高度的约 **22%–78%**，平常完全透明；它们并非全画面手势。为**确保右侧滑动不再使页面滚动**，右侧触控条使用 `touch-action: none` 与非被动的 `touchstart/touchmove` 监听。这也意味着该窄条上原生 YouTube 点击行为会被遮挡，不能做到既让 iframe 接收同一次点击又从父页面捕捉全部手势。

## 安卓实测诊断

1. 在脚本管理器菜单点击 **「显示/隐藏边缘触控区域（调试）」**。视频左侧应有蓝色半透明窄条，右侧应有绿色窄条。
2. 在**绿色右侧窄条**上下滑动，应出现音量百分比，并且页面不再随手指滚动。
3. 在**蓝色左侧窄条**短按，应打开当前视频的控制/统计面板。
4. 成功后再次选择调试菜单，隐藏彩色提示，恢复透明。
5. 如果彩色窄条都没有出现：确认仍在 Holodex Multiview、脚本已经启用、页面刷新完成、格子是 **YouTube 视频**而非 Twitch / 聊天格子。可先用菜单「选择视频查看统计（备用入口）」确认脚本识别到的视频列表。
6. 如果窄条出现但音量没有实际变化：测试 0%、30%、70%，并注意某些安卓浏览器可能限制嵌入播放器的软件音量调节。

脚本另有 **「启用/禁用透明边缘手势」** 开关：关闭后立即移除透明条，但仍可通过 **「选择视频查看统计（备用入口）」** 从油猴菜单查看统计。整个脚本也能通过「暂停 Holodex Touch Controls」禁用。

## 精简统计面板

| 字段 | 数据与意义 |
| --- | --- |
| **Connection Speed（Mbps）** | YouTube 内部 `getStatsForNerdsData()` / `getStatsForNerds()` 的 `bandwidth_kbps`，转换为 Mbps，代表 YouTube 对该路播放连接的带宽估计 |
| **Buffer Health（秒）** | YouTube 原生缓冲健康度字段，提供时才显示 |
| **播放时间** | Holodex 已使用的 YouTube IFrame API 提供当前时间/总时长；不依赖第三方 iframe 的原生统计脚本 |
| **当前／推荐分辨率** | 优先读取原生统计；字段缺失时若能读取视频实际帧尺寸，则标注「实际帧」，不冒充推荐值 |
| **播放状态** | 播放中、暂停、缓冲或未就绪 |

播放时间会在 Holodex 接口响应后优先显示，不必等待 YouTube iframe 超时。**没有设备总网速估算的回退**。如果 Connection Speed 为「—」，不代表网速为零，而是对应的 YouTube 内部统计没有成功读取。脚本仍有「切换 YouTube 原版统计」实验性入口。

- 已做 JavaScript 语法及模拟测试：透明触控条创建、右侧阻止页面滚动、音量手势、左侧点击、合成点击去重、左侧滚动不误触、布局/视频切换保护，以及原生统计字段解析。
- **尚未在你的安卓浏览器完成 v0.3.1 真机回归**；真实页面中的浏览器差异、Holodex 内部布局变化和 YouTube 原生统计方法可用性仍需确认。
- 如果浏览器完全不允许覆盖或触摸事件被其他脚本阻止，可通过菜单关闭手势、继续使用 Holodex 原生媒体控制面板。
