# Holodex HyperChat Cleaner

面向 **YouTube、Holodex Watch / Multiview** 的轻量级用户脚本，包含聊天清理、频道资料修复、PC / Android 一键添加视频，以及 **Holodex 多视图 PC／安卓智能自动播放、Holodex／YouTube 通用手机手势、音量、播放速度及真实画质控制**。

## 安装

1. [HyperChat Cleaner](https://raw.githubusercontent.com/lyl7410/Holodex-HyperChat-Cleaner/main/userscripts/hyperchat-cleaner.user.js)
2. [Channel Name Fix](https://raw.githubusercontent.com/lyl7410/Holodex-HyperChat-Cleaner/main/userscripts/channel-name-fix.user.js)
3. [Holodex Quick Add（PC + Android）](https://raw.githubusercontent.com/lyl7410/Holodex-HyperChat-Cleaner/main/userscripts/holodex-mobile-quick-add.user.js)
4. [Holodex Touch Controls（Holodex／YouTube 手势、倍速、画质＋多视图自动播放）](https://raw.githubusercontent.com/lyl7410/Holodex-HyperChat-Cleaner/main/userscripts/holodex-touch-controls.user.js)

四个脚本可独立安装。Quick Add 不要求安装另外三个脚本；Touch Controls 独立提供 Holodex 多视图 PC／安卓智能自动播放，也在 Holodex 和普通 YouTube 播放页提供手机触控、统计、倍速与原生画质控制；其他功能按需安装。更新时覆盖同名脚本并刷新相关页面，不要同时启用多份旧版。

## 功能

### Cleaner v2.4.2

- 隐藏 YouTube 原生聊天的顶部、输入区、置顶、投票、打赏条、会员通知。
- 隐藏 HyperChat 顶部提示、部分付费卡片、消息三点菜单。
- 付费留言（Super Chat / 贴纸）可通过油猴菜单切换。
- 聊天字体大小可调整，Holodex 有 **Aa** 设置入口。
- Holodex Multiview：精简聊天栏，隐藏左右频道切换箭头和频道下拉箭头，保留点击频道名称选择频道。
- **手机竖屏工具栏精简**：仅在竖屏且页面宽度不超过 900px 时隐藏绿色「新增空白区域」按钮和链条「分享布局」按钮；横屏仍可使用。
- YouTube 聊天栏右下角（距底部约 50px）显示按需使用的 ✎ 临时发言按钮。电脑端鼠标悬停显示；移动端半透明。
- 原生输入组件存在且可见时尝试展开；不存在时不会创建虚假的聊天输入框。

### Channel Name Fix v2.6.2

- 修复 Holodex 多视图聊天栏里的 **11 位 YouTube 视频 ID** 显示为频道名，保留原生频道下拉选择。
- 补全当前视频在 Holodex Vuex 中的频道名称、频道 ID 和直播标题，媒体控制面板显示正确直播资料。
- 媒体控制面板与布局调整面板：为 Holodex 没有收录头像的频道覆盖显示真实 YouTube 频道头像。
- **头像缓存优化**：油猴持久缓存视频资料及按频道 ID 共享的头像 URL；当前标签页预加载并复用已解码头像图片。同频道的多场直播共享最新的头像地址。
- **减少反复开关面板时的闪烁**：检测 Vuetify 弹窗显隐变化，面板显示时尽早挂载已经预热的头像；同一视频更换头像时，旧头像会保留到新头像加载完成。
- 保留油猴菜单：查看缓存、重新获取当前视频资料、清空缓存。

## 使用说明

### Holodex / YouTube Touch Controls v0.6.8（YouTube 画质接口测试版）

- **v0.6.8 · YouTube 画质接口测试**：普通 YouTube 网页播放面板增加目标画质、刷新档位、应用画质。优先查询内部 `getAvailableQualityData()`/`getAvailableQualityLevels()`，并尝试非公开的 `setPlaybackQualityRange()`；读取不到可用档位但内部设置函数存在时，显示明确标注「尝试」的候选档位。设置后核对 `getPlaybackQuality()` 和统计格式 ID，不把请求成功误报为实际切换成功；保留原生齿轮为后备入口。**本功能仅在测试分支，未通过安卓实机验证，非公开 API 可能随 YouTube 更新失效。**
- **v0.6.7 · 常驻时间与原生连接速度**：Holodex 多视图每个可见视频与普通 YouTube 视频的左上角新增小标签，可直接轻点切换「播放时间 → 连接速度 → 同时显示 → 只留小入口」，选择自动保存。时间复用 v0.6.6 点播／直播逻辑，速度来自 YouTube 原生 Stats for nerds；最多保留 6 秒以内同一视频真实样本，过期标「上次」。PC 和安卓均有入口，不影响原有手势、倍速和自动播放。
- **v0.6.6 · 播放时间优先显示**：纠正 v0.6.5 在检测到直播时用「🔴 直播中」**覆盖整块播放时间**的回归。现在普通 YouTube 与 Holodex 多视图均显示播放进度：点播／回放展示「当前时间 / 总时长」，直播展示**当前播放器时间轴位置**、另在下方标注「🔴 直播中」，不把 1 小时 DVR 窗口当成直播总时长。播放器的视频元素暂未提供进度时，可尝试读取 YouTube 的 `getCurrentTime()` / `getDuration()`；播放时间卡片字号提高。
- **v0.6.6 · 真实连接速度短时保留**：继续沿用 v0.6.5 原生统计采集；当 YouTube 某次采集暂时缺少带宽字段时，最多显示 **6 秒以内同一视频最后一次真实 Mbps 采样**，明确标为「最近一次采样」，超过期限或切换视频后显示 `—`。**不将缓冲时间、下载速率或估算带宽冒充真实 Connection Speed**。若浏览器完全不开放原生速度字段，仍需使用「YouTube：连接速度诊断」查看可用接口。
- **v0.6.5 · 连接速度再次修复**：扩大普通 YouTube 原生统计解析范围，兼容 `connection_speed`、`connectionSpeedKbps`、`bandwidth` 及嵌套字段、英文/中文/日文文字和 Mbps/Kbps 单位；手机浏览器即使不提供 `isVideoInfoVisible()`，也可尝试静默启动原生统计并读取真实 DOM。新增油猴菜单「YouTube：连接速度诊断」，报告真实播放器接口、原版统计元素、采集开关及具体来源，便于定位仍然显示 `—` 的机型。**不以网络测速或缓冲推算冒充 YouTube Connection Speed**。
- **v0.6.5 · 直播状态简洁化（历史记录，已由 v0.6.6 修正）**：此版本会用「🔴 直播中」替换播放时间，导致直播播放进度消失；v0.6.6 已改为时间和直播状态同时显示。
- **v0.6.4 · 直播时间纠正**：普通 YouTube 视频页出现播放时间 `0:16:13 / 1:00:00` 时，可能实际是在看直播，`1:00:00` 是直播 DVR 时间轴的窗口长度，而非总播放时长。新版优先读取播放器直播状态、当前视频匹配的 YouTube 播放信息和 LIVE 徽章：正在直播时明确显示 **「🔴 正在直播」**，附注「时间轴位置（非直播总时长）」；真正的点播视频仍显示「当前进度 / 总时长」。已结束的直播回放不会仅因存在 `isLiveContent` 标志而错误标记为正在直播。
- **v0.6.3 · 恢复 Connection Speed**：修复普通 YouTube 手机／桌面面板播放时间、分辨率和缓冲正常，但「连接速度」显示「—」的问题。原先 YouTube 页只取少量播放器字段；现在复用 Holodex 已实现的原生统计原理：打开快捷面板时静默启用 YouTube Stats for nerds（原版覆盖层隐藏但持续更新），实时读取多种原生 Kbps 字段或统计面板实际 Connection Speed；关闭面板恢复原版统计开关，不假造估算网速。部分浏览器不开放数据时仍如实显示「—」。
- **播放时间说明**：`当前时间 / 总时长`，如 `0:01:41 / 0:03:35` 表示已播 1 分 41 秒／视频总时长 3 分 35 秒。直播的右侧数值可能只是播放器暴露的回看窗口，并非直播真正持续时间。

- **v0.6.2 · 单排五档倍速**：Holodex 与普通 YouTube 面板都改成 **1×、1.25×、1.5×、1.75×、2×** 五个按钮，一排展示；取消 0.5×、0.75×。根据实际播放器读回的倍速高亮，直播不支持时提示而非假装成功。Holodex 保留当前实际分辨率，以及直达对应 YouTube 视频的画质入口。
- **v0.6.2 · YouTube 画质入口及手机手势**：普通 YouTube 面板移除实际不可用的「画质选择」下拉框与「应用」按钮，只保留当前实际解码分辨率和**「打开画质设置」**。新入口尝试在当前视频附近查找手机／桌面 YouTube 的真实设置齿轮；找不到时提供「轻点视频 → 设置 → 画质 → 高级」及浏览器桌面版指导，**不会声称已切换画质**。播放中触控区仍位于页面顶层并随视频位置更新，左侧打开面板，右侧调音量，不显示常驻悬浮图标。
- **画质 API 兼容性**：YouTube 官方 IFrame API 自 2019 年起不支持 `setPlaybackQuality()`；因此脚本只尝试操作 YouTube **原生画质菜单**并读取它确实列出的选项。成功点击不等于解码画质即时变化；若 YouTube 更改了 DOM 或禁用 iframe 原生菜单，则会明确提示不可用，不会虚报切换成功。面板显示的是实际视频帧尺寸，可能与选择的目标画质不同。
- **智能自动播放 v0.5.0（PC／安卓）**：首次进入、刷新、Quick Add / Holodex 添加视频、切回多视图时，识别并尝试启动未播放的视频。**播放中与缓冲中的视频绝不重启**，已结束录像不自动重播。
- **刷新后误暂停修复 v0.5.1**：首次初始化 `-1` 状态先等待约 3.2 秒，媒体进入 `5`（已加载待播放）后立即尝试；YouTube 自动播放受浏览器拦截而迅速暂停时，不再轻易误记为用户手动暂停。旧版可疑缓存不继承，仍保留稳定播放后手动暂停的会话保护。
- **浏览器拦截与静音回退修复 v0.5.6**：安卓实际截图确认 GM 与页面代理都处于**已启用**，但两路视频都被浏览器拒绝有声自动播放。新版对**用户明确允许**的静音回退改为先执行 YouTube `mute()`、再同步 Holodex 的 Vue 静音属性、延时约 220ms 才调用 `playVideo()`；避免播放早于静音生效。诊断及菜单可一键询问是否启用，仅处理未播放的格子；已经播放、缓冲或手动暂停保护的视频不被重启或改音量。静音模式仍可能被浏览器拒绝，重试有次数上限。
- **保护已在播放的视频**：脚本发起自动播放时避免触发 Holodex 原生首次播放 `muteOthers()` 导致其他直播被静音；播放成功后维持已有音量状态。
- **安卓触摸控制不变**：两侧 36% 宽／78% 高的透明触摸区、灵敏度 0.4×–2.5×、可选左右长按 600ms、临时音量提示、原生 Connection Speed / 缓冲健康度 / 直播延迟 / 时间 / 分辨率面板。统计上半部及面板外区域可点按收起。
- **数据及权限**：基础自动播放、音量手势和播放时间不依赖在 YouTube 第三方 iframe 内注入脚本；原生连接速度、缓冲及延迟则需要 iframe 内脚本权限及非公开播放器字段。独立 Quick Add 仍可能按其自身策略将新增视频静音。
- [安装、智能自动播放设置与安卓手势说明](docs/touch-controls.md)。PC 可通过油猴菜单打开设置，安卓可通过菜单或统计面板的 ⚙ 进入。

### Quick Add 通用版 v0.3.0（PC / Android）

1. **PC**：在 YouTube 视频网页右下角点击半透明 **＋H**；鼠标悬停显示文字。也可使用 `Alt+Shift+H` 快速添加，`Alt+Shift+N` 新建接收分屏，或 **Shift＋点击** ＋H。
2. **Android**：保留触摸显示 ＋H、闲置 4.5 秒隐藏的原有操作，不需要重新安装第二个脚本。
3. **Holodex 接收页**：优先通过已指定的分屏接收视频。PC 模式允许后台接收，不强制切走当前 YouTube 标签页；手机仍建议切回 Holodex 处理队列。PC 接收页还可按 `Alt+Shift+R` 接管当前分屏。

优先使用 Holodex 中保存的**默认自动布局**；没有合适预设时 PC 优先桌面布局、手机优先移动布局。新增后继续使用 Holodex 原生方法合并，并尝试自动播放；浏览器仍可能限制后台、有声自动播放。

详细步骤与排错：[PC 快捷操作使用说明](docs/desktop-quick-add.md) · [Android 使用说明](docs/mobile-quick-add.md)。

### 聊天清理和频道名称

- 在 Holodex Multiview 中点击频道名称区域，仍可展开原来的频道选择列表。
- ✎ 发言功能取决于当前 YouTube 聊天 iframe 是否实际提供文字输入组件、登录状态及直播权限。部分嵌入环境无法恢复输入区。
- 若出现只剩表情、爱心而没有文字输入的情况，说明 YouTube 未提供可用编辑器；此脚本不会模拟发言。
- 若频道名称未出现，检查网络是否允许访问 YouTube oEmbed；部分私有、受限制或不支持 oEmbed 的视频无法解析。

## 已知限制

- Holodex/HyperChat 的 DOM 结构可能变化，特别是多视图工具栏和聊天消息样式。
- 新版优先通过 Holodex 的 Vuex 同步频道名、频道 ID 和直播标题；当页面组件取不到 Vuex 时，频道名称退回仅替换显示文本。
- 视频元数据缓存：完整资料 14 天，不完整资料 24 小时；头像 URL 按频道持久保存，图片文件由浏览器 HTTP 缓存管理。在同一标签页内，预加载图片对象会保持在内存中（最多约 80 个）。
- **第一次获取头像**仍依赖网络，不能保证不显示默认头像；关闭/重开面板通常不需要再次取回频道资料，但浏览器是否联网重验图片由其缓存策略决定。
- 部分受限视频或频道，以及无法从 YouTube 网页取得真实头像的情形，仍可能回退为默认图标。
- 该版本未在所有桌面/安卓浏览器组合上完成回归测试；若更新后仍有默认头像，可在油猴菜单中选择「重新获取当前视频资料」并刷新页面。
- Quick Add 运行于浏览器网页，不能直接接收 YouTube App 的 Android 分享，也不能保证后台页面立即处理或自动有声播放。YouTube 和 Holodex 需使用同一浏览器、同一脚本管理器中的同一份脚本；普通模式和隐私模式不应混用。
